\# ML Classification Dashboard (Streamlit App)



\## Problem Statement

Predict whether a person earns >50K or <=50K using the Adult Census dataset.



\## Dataset Description

The Adult Census dataset contains demographic and employment-related attributes.

Total records: 48,000+

Features: 14+



\## Models Implemented

1\. Logistic Regression

2\. Decision Tree

3\. K-Nearest Neighbors

4\. Naive Bayes

5\. Random Forest

6\. XGBoost



\## Evaluation Metrics Used

\- Accuracy

\- AUC Score

\- Precision

\- Recall

\- F1 Score

\- MCC Score



\## Observations



| Model | Observation |

|------|-------------|

| Logistic Regression | Excellent performance on encoded data |

| Decision Tree | Very high accuracy, may overfit |

| KNN | Slightly lower performance |

| Naive Bayes | Very fast and accurate |

| Random Forest | Strong performance |

| XGBoost | Best overall performance |



\## Streamlit Features

\- CSV upload option

\- Model selection dropdown

\- Prediction display
